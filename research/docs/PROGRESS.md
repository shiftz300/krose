## 当前结论

[效果加载与初始上传](architecture/EFFECT_LOAD_STATE.md)已核对 122 项独立程序的 1668 次加载及七组 Hall→EQ→No Effect 序列。原加载器清零常数尾部，提交完整 80/160 字占用区，程序复制只覆盖新范围。EQ A50/51 随加载以零值上传；13 项零代码变体排除。数据 RAM、运行平滑和实际音频仍待验证。

[鼓轨到真实声部](architecture/DRUM_VOICE_PLAYBACK.md)已从原 PPAT、本机 MIDI 输入连接鼓组选样、起音和正常刷新。12 条轨迹推进 53760 个音乐 tick，建立 390 个声部，完成 6720 次控制更新与 18954 次 TG 提交。循环与停止事件、采样地址、主侧增益及两套调度结果通过比较；TG 启停和零幅度目标采用即时应答，实际芯片音频与宿主时基仍待验证。

[四段 EQ 的 B2 局部程序](architecture/EQ_B2_PROGRAM.md)核对七槽初始化与 331 个原厂槽位的 6620 次回调：完整程序/常数一致，两组端点引用与 46 对声道字段镜像已定位。No Effect 的常数 0 在 IFX/MFX 分别初始化为 8388607/0。61 组不同端点另比较两个未验证的主机候选，D100 / IFX2 在固定权重 0.5 时约相差 2.025 dB；该差值只用于区分候选，原 DSP 运算与 A50/51 作用仍待恢复。附程序、候选频响与动态 CSV 和配图。

[逐键 MIDI NRPN 连通](architecture/DRUM_NRPN_LIVE.md)已执行原事件路由、通道分发、控制复制和逐键写入。1544 条边界消息通过独立状态比较；12 条自然轨迹完成 12288 次更新、9334 次控制提交，13716 次核心状态与独立整数模型一致。选择的一半改变会保留另一半，Null RPN 切回后仍可沿用旧键号；来源 0/5 的六组配对包络一致，影子副本按来源分别处理。附事件图与两份消息 CSV；完整 MIDI Note On 路由、动态踏板与 TG 音频未并入本项。
