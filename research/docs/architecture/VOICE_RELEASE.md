# 音符释放、踏板保持与声部回收

KROSS 2 v1.2.4 · 阶段 03 · 2026-11-01

一次 Note Off 会找到最近建立的同音高声部组，记录释放力度，再决定继续保持、开始包络释放，或取消尚未启动的声音。松键后的声部立即进入可替换队列；可用数量要等真正回收时才增加。

## 1 同音高重复按键如何匹配

`0x1F61F8` 把一次 Note On 返回的声部链挂入振荡器列表，并把首个返回槽的编号写入各声部 `+17`，作为同组标记。挂入操作逐个插到表头，因此新的一组位于旧组前面。

释放入口 `0x1F60A4` 先找音高相同、key-on 标志 `0x80` 有效的普通声部。找到后记录它的组标记，继续处理后面同音高、同组且仍有 key-on 标志的声部。遇到不满足条件的普通声部就停止。类别字段不为 `-1` 的项另交专用入口处理。

原指令轨迹如下：

| 操作 | 振荡器列表或释放结果 |
| --- | --- |
| 音符 60，第一组返回 `0 → 3 → 2 → 1` | 挂入后 `1 → 2 → 3 → 0` |
| 音符 60，第二组返回 `4 → 5` | 列表变为 `5 → 4 → 1 → 2 → 3 → 0` |
| 音符 62，返回槽 6 | 列表变为 `6 → 5 → 4 → 1 → 2 → 3 → 0` |
| 第一次 Note Off 60 | 释放 5、4 |
| 第二次 Note Off 60 | 释放 1、2、3、0 |
| 第三次 Note Off 60 | 无待释放的普通组 |
| Note Off 62 | 释放 6 |

释放力度写入组内每个声部的 `+1B`。这里得到的是普通 PCM 组的后进先出行为；类别专用路径和单音重触发需要分别验证。

## 2 松键后的六条分支

单声部释放入口为 `0x1F7CC8`。它先清掉 `0x80/0x02`，设置 `0x01`，随后按以下顺序判断：

| 条件 | 行为 |
| --- | --- |
| 保持位图包含该音符，且控制器 66 开关有效 | 设置 `0x100`，继续保持 |
| 音色允许延音，CC64 ≥80 | 设置 `0x03`，继续保持 |
| 等待计数 `+208` 为负 | 清空等待、设置就绪位 `0x08`，在松键后触发声音 |
| `+20D` 不允许释放 | 保留声音 |
| 声音仍在等待，或尚有就绪位 `0x08` | 取消待启动声音，清空立体声配对与等待，返回 1 |
| 已启动且允许释放 | 设置释放相关标志，进入 `0x1F8AF4` |

3,456 组检查覆盖按键位图、控制器开关、延音阈值、负/零/正等待、时间等待和释放许可。分支执行使用原指令；实际包络与 TG 更新在 `0x1F8AF4` 边界截获。

负等待值与用户手册的 **KeyOff** 模式一致：该模式让声音在松键时开始。手册位置为 Parameter Guide 的 P–BASIC / Note-On Control，印刷页 8。[R1]

## 3 踏板会修改哪些声部状态

振荡器的延音开启入口为 `0x1F5E44`，关闭入口为 `0x1F5E98`，保持踏板入口为 `0x1F5F4C`。80 个声部情况验证了它们的标志和回调行为。

OSC 参数 `+2C` 的 bit 7 会切换处理方式。置位时，开启/关闭踏板可分别写入 Amp EG 内的 `+32/+33` 两个锁存字节，也可能直接请求释放。未置位时，关闭踏板把标志 `0x02` 有效的声部送入释放流程；其余类别声部调用专用入口。该参数的准确界面名称继续与参数描述符对照。

保持踏板开启时，标志 `0x02` 有效的声部增加 `0x100`；关闭时，标志 `0x01` 有效的声部重新经过释放管理器。音色层还会把通道保存的按键位图交给单声部释放判断，二者共同维持保持状态。

## 4 松键、替换与真正回收

释放管理器 `0x1FD4F4` 先把普通声部移到候选队列尾部，再处理保持或包络释放。这个过程保持可用计数不变。原指令连通实验使用八个槽：

```text
两次 Note On 各占两个槽：0、1 与 2、3
仍有空闲槽：4、5、6、7；可用数 = 4

Note Off 释放最近的一组：3、2
候选顺序：4、5、6、7、3、2；可用数仍为 4

随后连续申请五次：4、5、6、7、3
第五次开始替换已经松键的槽 3

强制停止槽 2：移出声音列表，可用数增加到 1
```

这条实验实际执行了分配器、组挂入、振荡器 Note Off、释放管理器、单声部状态机和强制停止后的列表清理。TG 复位/停止写入与包络释放体均截获。它验证了“已松键、仍在释放”和“已经可用”对应不同的管理状态。

## 5 音色层的 Note Off 分发

复音模式下，`0x2743E4` 经 `0x272C3C` 调用 PCM 振荡器虚表 `+18` 槽。即使松开的音符落在音色键区之外，也会继续分发给两个振荡器；键区只决定音色按键计数是否递减。计数为零时不会继续减到负数。

28 组检查覆盖键区边界和计数 0、1、2、65535。对应 Note On 的键区筛选、计数先后顺序见[演奏控制报告](RUNTIME_FLOW.md)。
