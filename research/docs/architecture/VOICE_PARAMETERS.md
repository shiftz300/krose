# PCM 声部参数如何建立

KROSS 2 v1.2.4 · 阶段 03 起始记录 · 2026-11-01

选层结果进入 `0x1F6958` 后，固件检查描述符和采样区域，计算层音量，设置反向与起始偏移，再把结果交给声音控制初始化。本轮执行了普通旋律分支的参数构造、区域查找和参数复制，共 640 组检查；区域缺失与采样缺失两条失败路径也已通过。

## 1 描述符与素材检查

普通层描述符首字节的低两位必须至少有一位置位。低两位全零时，参数构造立即返回 `-1`。因此，[力度选层](RUNTIME_FLOW.md)返回的候选还需要经过这个筛选。

普通 PCM 区域结构包含 128 项有符号字节的音符映射。映射值为 `-1` 时，区域查找返回空；其余值与区域头中的起始索引相加，得到银行内 20 字节区域记录的编号。参数构造再从区域记录找到采样元数据。

本轮合成银行采用 64 字节采样元数据。汇编中另有 100 字节元数据分支，尚未执行该分支的完整行为。

## 2 交叉权重怎样影响音量

恢复的整数计算为：

```text
层音量 = uint8((描述符音量 × 交叉权重) >> 15)
```

例如，描述符音量为 127、交叉权重为 16384，结果为 63。权重为零时，本函数仍可成功建立素材参数，同时把层音量写成零；后续是否启动或保持声部由声音控制函数决定。

该结果写入公共初始化上下文 `VA C165D9A4`。相邻字段保存音高、区域调音和控制标志。这个临时上下文说明初始化过程还依赖共享状态，复现时需要保留调用顺序。

## 3 反向与起始偏移

描述符 `+5` 的 bit 7 提供反向标志，低四位提供起始偏移编号。反向还受 Tone Adjust 和素材能力查询影响。本轮固定 Tone Adjust 为未设置、素材支持反向，验证描述符标志能保留到声部 `+20C`。

起始偏移写入声部 `+20A`；如果编号超过区域头给出的上限，固件改为 0。测试采用上限 4，验证了 0、3、4、5、15 五个值，后三者中的 5 和 15 均归零。

## 4 参数复制保留什么

`0x1F716C` 从临时对象复制到实际声部，只复制指定字段和一段 53 字节的控制区。TG 槽号、对象头、列表身份、配对字段和分配类别保留原值。测试先把目标填为 `A5`，再核对复制区逐字节相等、身份区仍为 `A5`。

| 已核对字段 | 声部偏移 |
| --- | --- |
| 所属振荡器、音色与运行参数指针 | `+04 / +08 / +0C` |
| 音符与处理后力度 | `+12 / +14` |
| 采样、鼓相关参数与区域指针 | `+20 / +24 / +28 / +228 / +22C` |
| 起始偏移、素材属性、反向与控制标志 | `+20A` 至 `+20E` |
| Program 与振荡器参数指针 | `+21C / +220 / +224` |

## 5 分配器评分来自哪里

声部替换所用的 `+23C` 评分来自 TG 读回。更新函数 `0x1F9828` 先检查对应 TG 状态位；状态有效时调用 `0x12E6E0`，把结果的低 16 位写入该字段。状态为零时保留原缓存。

读回函数先通过 TG `+400` 寄存器选择槽，再对 `+428` 连读两次，采用第二次结果。槽号 120 及以上返回零。启动函数的静态指令先把缓存初始化为 `0x7FFF`。

1,440 次更新检查覆盖 120 个槽、两种状态和六个寄存器值；读回函数另外检查 768 次。所有寄存器均为模拟内存，未访问芯片。现在可以确定评分是硬件读回缓存；其物理量是否对应当前电平，还需 TG 寄存器语义佐证。

## 6 验证边界

检查覆盖描述符低两位的四种值、四档层音量、四档交叉权重、两个反向值和五个起始偏移，共 640 组。实际执行了参数构造、20 字节区域查找及参数复制。外部控制器开关、Tone Adjust、银行编号映射和音高计算提供固定输入；TG 启动和音频执行尚未进入。

后续已连通 `0x1F7278` 的完整控制初始化和 TG 命令生成，见[声部启动与回收](VOICE_TG.md)。本页保留参数构造实验的边界；鼓组、扩展银行、采样装载失败的完整回收、单音与连奏仍需追加检查。
