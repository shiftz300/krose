# 声部构造失败后如何收尾

KROSS 2 v1.2.4 · 阶段 03 · 2026-11-01

管理器会先为选中的力度层预留全部槽位，随后逐层构造。成功的声音组成返回链，未使用的槽位统一归还。256 组失败注入确认了可用计数的恢复；另两组实验执行原参数构造函数，复现了右声道键区缺失时的配对残留。

## 1 预留与归还

`0x1FDC8C` 先计算每层所需槽数：单声道一个，立体声两个。它调用强制批量分配，再按层、按侧执行 `0x1F6958` 参数构造和 `0x1F7278` 控制初始化。

成功一次，已使用槽数增加一次。参数构造返回负数或控制初始化返回零时，该槽不计入成功数。第一侧失败会直接跳过本层第二侧。处理完所有层后，固件从预留数组尾部向前归还多余槽位，并清掉管理器忙标志。

256 组检查组合了两层的单/立体声模式、参数失败、初始化失败、TG 槽号正/反序和普通/延迟模式。八槽夹具中，每组都满足：

```text
可用槽数 = 8 − 成功构造的声音数
可用槽与返回声音没有交集，合起来恰好覆盖全部八槽
```

这说明已检查分支的计数和预留槽归还成立。构造函数的失败结果由测试提供；异常展开路径尚未纳入。

## 2 第二侧失败时留下什么

立体声第一侧在初始化前，已经记录了第二侧的槽指针。第二侧失败后，管理器继续处理下一层，最后归还剩余槽；当前路径没有同步清除第一侧的配对指针。

| 合成输入 | 返回声音 | 第一侧的配对指针 |
| --- | --- | --- |
| 第一层右侧缺失，第二层两侧有效 | 槽 0、1、2 | 槽 0 仍指向槽 1；槽 1 已成为第二层主声部，与槽 2 配对 |
| 第一层右侧缺失，第二层也缺失 | 仅槽 0 | 槽 0 仍指向槽 1；槽 1 已归还可用队列 |

这两组使用原 `0x1F6958`、区域查找和参数复制。测试把右侧音符映射设为 `-1`，由原指令产生失败返回；控制初始化仍在函数边界截获。

## 3 还要核对什么

目前可以复现合成素材缺项下的配对残留。后续[板载素材检查](FACTORY_REGIONS.md)已遍历七对旋律立体声的全部音符，两侧有效性一致，未发现单侧键区缺失。扩展库、银行缺失或只装载一侧的情况仍需沿素材装载与银行切换路径核对，再观察后续延迟启动和抢占如何使用残留指针。

因此，这一记录暂时用于确定后续检查点。它不代表已经确认原厂预置或实机存在可触发故障。
