# 研究工具索引

按主题整理 240 个文件，保留原文件名与导入关系。索引包含可执行脚本、模型和支持源码；具体重跑命令与截获边界见对应研究章节。

## 常用入口

```sh
python3 research/tools/firmware_runtime_verify.py
```

该入口核对现有证据与报告，不访问设备，也不重跑全部 ARM 矩阵。单项 `--verify-arm` 执行需要宿主允许 Unicorn JIT。

采集、注入与导出脚本作为历史工具保留，其用途及条件以章节说明为准。本次整理只执行目录和证据复核。

`layout.py` 为旧文档中的 `tools/`、`output/` 提供路径兼容。旧工具指纹与结果按历史版本保留；变更源码后需按章节重新生成证据。模板在 `templates/`。
