# B094 Breathy Bells

核对输入：冻结音色库中的 B094，原厂 Program 数据 SHA-256 为 `2746de352ebe623de91ebba1d86bc1dceed95b3dc51d0e9138ea9d3c0a4ad1e9`，与资源清单一致。公式取自已核对 SHA-256 的 KROSS 2 v1.2.4 固件。

| 项目 | 原厂数据 | 修复前 | 当前处理 |
|---|---|---|---|
| IFX | Stereo Graphic 7EQ；Trim 35%，最高频段 +6 dB | 已带入 | 保留 |
| MFX1 | Multitap Cho/Delay，四抽头 | 通用双通道 Chorus 近似 | 仍为近似 |
| 合唱 LFO | 索引 42，显示为 1.00 Hz | 错按 42 Hz，再限到 5 Hz | 修正为 1 Hz |
| 四抽头深度 | 15、16、15、15 | 遗漏，使用默认 70 | 单深度近似采用平均 15.25 |
| 四抽头时间 | 57、30、40、26 ms | 未恢复独立抽头 | 尚未恢复 |
| MFX2 | Plate：3.6 s、HiDamp 30%、Wet/Dry 24% | 通用 Plate 近似 | 保留现有近似 |

原厂 LFO 的显示函数在 `0x745b8`，调用 `0x7457c`：索引 `v≤40` 时为 `2v/100` Hz，`40<v≤52` 时为 `(10v−320)/100` Hz，其余为 `(100v−5000)/100` Hz。此前忽略了该换算，造成此音色的合唱调制快了五倍。Tap 时间函数 `0x746b4` 调用 `0x97bf4`，索引 0–99 直接对应毫秒，之后为 `10v−900` 毫秒。

修复仅改变已解析的 FX 参数。48 kHz 下 C4、C6、力度 100 的干声渲染与修复前逐字节相同；含 FX 的渲染已改变。测试输出未削波，无法据此把用户描述的高频干涉全部归因于合唱。四抽头算法、各 Tap 声像与反馈、动态调制源，以及原厂混响前置 EQ 仍有差异。

本地对照文件位于 `dist/local/b094-audit/`：`before`、`after`、`dry`，均为 48 kHz，试听统一增加 20 dB。它们是插件渲染，不是原琴录音。严格的听感一致性比较仍需同 MIDI、同输出条件的原琴录音。
