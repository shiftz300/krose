# FX 收放动画

2026-11-04。收放改为连续加减速，中途再次点击时承接当前速度。面板布局、材质、遮罩形状和音频处理保持原样。

## 动作变化

原动画为 220 ms 的三次缓出，起步速度最高；再次点击会重新开始缓动。现在使用临界阻尼曲线，起步速度为零，约 200 ms 完成 95% 的行程，随后轻缓收尾。余量小于 0.28 逻辑像素且速度足够低时落到终点，停止动画重绘；一般约 450 ms 完全结束。

`FXMotion.h` 保存位置、速度、目标和起始时间，按单调时钟计算当前位置。再次点击时同时继承位置和速度。它不依赖逐帧积分，不产生弹跳，也不分配内存。现有离屏纹理继续复用。

在理想 60 Hz 采样下，遮罩半径的最大单帧变化从 115.77 降到 80.39 逻辑像素，减少约 31%。这是运动曲线的变化幅度，不是帧率提升。新增测试覆盖快速反向 100 次、位置和速度连续性、范围、终点及不同采样频率。

## 原生窗口测量

同一台 Mac、同一 Cocoa 宿主和默认 Concert 音色，前后各运行三次，交替测试。每次收放 12 次，相邻点击约 600 ms，等待新旧动画均到达终点。基线二进制来自 `d4e654c`。表内取三次结果的中位数。

| 项目 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 动画 Draw 间隔中位数 | 16.66 ms | 16.54 ms |
| 动画 Draw 间隔 P95 | 18.90 ms | 19.83 ms |
| 单次绘制 CPU 中位数 | 0.356 ms | 0.336 ms |
| 单次绘制 CPU P95 | 0.632 ms | 0.607 ms |

目标刷新率仍为 60 Hz。测量未显示帧间隔波动改善；新曲线改善的是起步和反向的连贯性。收尾更长，因此每次操作的绘制帧数增加。Draw 间隔不等于屏幕实际呈现间隔，表内 CPU 时间不包含 GPU 完成时间。

10 张实际静态帧与上一版逐像素一致，包含整机、LCD、数值上限、分类、收藏及菜单。原生 Cocoa 测试覆盖中途反向、参数操作和关窗重开。原始日志与汇总见 [fx-animation](verification/native-ui/fx-animation/)。
