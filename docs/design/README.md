# KROSE 固定尺寸界面

设计画布为 **1472 × 648 逻辑像素**。页面宽度不足时只缩放整个画布，不改变控件坐标。产品面板源码位于 [editor/web](../../src/plugin/editor/web/)，按 HTML、CSS、面板逻辑和宿主绑定拆分。运行 `cmake --preset plugin` 会生成 `build/plugin/src/plugin/panel-preview.html`，用于离线设计核对；插件使用同源的 `editor.html`。

Page：[Krose UI 设计稿](https://chatgpt.com/space/page_7ac8da78136881919fb4032cf175ebaa)。

用户确认移除 Pad、鼓轨；本稿同时省去步进、整机采样与录音控制。保留 ARP、61 键、双轮和 SW1/SW2；右侧使用包络推子、演奏模式、滑音及 ARP 时序控制。

按最新要求调整：顶部整条浅白色边沿贴合外壳，下沿嵌入 3 px 状态灯条，石墨灰背板由上到下渐暗；黑色旋钮、短按键和双轮延续实拍材质。按钮放大，激活时暗红光透过键帽下半部，内侧底边带有反光。旋钮指针、轮上刻线和推子横线采用与效果模块一致的白色灯芯和局部辉光。KROSE 字标为浅灰色。初始化期间各灯呈灰色。就绪后，顶部灯带随 FX 状态切换，展开时呈半透明淡红色，收起时亮白色。旋钮、双轮和推子亮白色。右上方 Maincore 标志从左侧大理石取纹，以 37 px 静态 SVG 绘制，实心圆角三角右下方镂空一个小圆角三角，与 VOLUME 旋钮同列，中心与左侧 FX 字标等高。

CATEGORY 与面板模式说明表已移除。顶部使用音色下拉框；LCD 放大至 600 × 212 px，复刻宽斜面、深色内框、内侧上沿阴影与下沿窄反光的下凹结构。屏幕采用可读的像素字体，顶部 PROG 模式条连接四个斜肩页签 MAIN、TONE、FX、ARP。主页居中显示音色名，编辑页以反白条标出当前音色，数值下方画线；Tone、效果槽参数、Pattern、Rate、Gate、Swing 都可在 LCD 内配置，顶部速度区可切换 Host。屏下恢复前一个、后一个、BROWSE、SAVE、COMPARE 五个实用按钮。

左侧六只旋钮按两行三列排列，上排为 GLIDE、VALUE、PAN，下排为 CUTOFF、RESONANCE、VELOCITY。ARP 与右侧推子读数同高，LATCH 与演奏按钮同高。下排 +00 字形底边与 LATCH 键帽底边对齐。ARP、LATCH 与下方的 1 号键在同一列，键帽均为 65 × 34 px。旋钮矩阵居于该列和 LCD 之间，两边各留 47 px。右侧 VOLUME 与左侧 GLIDE 的标签、旋钮和读数分别水平对齐。灰黑色 PRESET 栏与 EG 选择行中线对齐。四根包络推子与下方演奏按钮对齐，琴键几何保持原值。

左侧三角斜切区域露出带棕色纹理的暖米粉色大理石底面（参考图取样 #E5D3C8），石面与上层玻璃共用同一条边界。边缘沿弧线起伏，局部保留成簇的短擦痕，擦痕垂直于当地边缘，在 VALUE 标签上方收住。玻璃保留斜向反光。深棕色直立罗马衬线 FX 的字形中心对齐两条淡红轨道的十字交点，可用鼠标或键盘切换展示。展开时显示石面、淡红轨道、玻璃和效果模块；收起时石面退回 FX，只留下石纹字标。第 1 槽位于交点下方，与 ARP 同列；上排第 2、3、4 槽分别与 GLIDE、VALUE、PAN 同列。每个模块有向右下的投影、暖米嵌边和白色上沿灯，悬停或聚焦可见名称。FX 下方的棕色三角朝上，右侧的三角朝右，两者距字形各 15 px。EQ 显示参数曲线，母带与普通限制器分别用淡黄和灰色表盘、红色指针与弧形刻度显示参数示意，混响用三维切片占位。图形由预置和编辑值生成，实时音频分析待接入。

键盘使用统一尺寸：36 个白键，每键节距 34 px、键长 216 px；25 个黑键，宽 20.4 px、长 134 px。白键长宽比约 6.35，黑键宽为白键的 60%，长度约为白键的 62%。两黑键、三黑键按半音结构排列，黑键中心由同一白键节距计算。比例按照片可见键面校正，未声称实测毫米尺寸。

八度按钮整组放在 y=589、高 34 px 的区域，按钮为 40 × 32 px，减号左边与 1 键左边对齐，加号右边与 2 键右边对齐。OCT 数字固定在个位，正负号占用同一空位。1/2 键帽到滚轮、滚轮标签到八度键帽各留 9 px。宽、窄预览均检查控件包围框，避免用裁切隐藏溢出。

四根推子是预置包络的快捷调整量，零位保留原参数；AMP 与 FILTER 独立保存。详细 EG 页面仍需保存固件原有阶段、电平和曲线。原生产品现有参数 ID 不在此原型中变更。

交互包含旋钮拖动和数值输入、推子、AMP/FILTER 切换、音色下拉框、Compare、LCD 内参数、键盘、滚轮、延音及 Panic。SAVE 仅保存 Page 原型状态。FX 页按四个出厂 Program 的已启用槽位排列，I 表示 IFX，M 表示 MFX。选中槽位后可以调四段 EQ、两种 Limiter 或该效果的常用参数。On 控制当前槽，IFX／MFX 控制整组。编辑按音色与槽号保存，COMPARE 可对照出厂值。效果与 Host 速度在原型内演示，尚未接入音频处理。SW1/SW2 后续由 Program 数据提供。

MAIN 状态行按 240 点逻辑宽绘制。类别图标取自 v1.2.4 固件的 14 × 12 点阵，类别和编号文字使用固件中带字宽的原生字形，AC 图标为 13 × 8。节拍数字及音符按参考图复原，125.00 BPM 为原型示例值。Lead 与 Pad 共用 SYNTH 图标。原始点阵、字形宽度和固件偏移见 [LCD 资源表](krose-lcd-resources.json)，[类别图标总览](krose-lcd-categories.png) 可直接核对。

其余页面的像素字体为项目绘制字形生成的 [krose-lcd-pixel.ttf](krose-lcd-pixel.ttf)，已内嵌到 HTML，Page 无需外部网络加载字体。

视觉验证确认 36 个白键、25 个黑键、4 根推子；主画布无图片或 SVG 截图，控件由 HTML/CSS 绘制。浏览器交互检查包括音色选择、ARP、包络目标独立值与 Panic。

原生 GUI 交接：FX 收放是独立的编辑器显示状态，默认展开，恢复上次视图；切换不得修改旁通、效果参数、音频或 LCD 编辑页。收起时移除模块的鼠标和键盘命中区域，FX 按钮继续可操作。当前交互实现在 Page 原型。
