# 声部调制链路

`ProgramEngine` 直接读取每个原厂 Program 的参数。独立 Concert 路径继续使用已接受的控制基线；插件参数编号、工程状态和界面布局不变。

## 处理顺序

每个声部按累计样本时间推进名义 62.5 Hz 控制时钟，保留原有 48 kHz 音量斜坡。宿主分块只影响调用边界。

1. 推进包络，读取本 MIDI 通道的控制值。
2. 按 LFO2、LFO1 的顺序推进和求值。交叉调制读取已更新的来源值。
3. 更新 Pitch EG 来源和两个有状态 AMS Mixer。
4. 计算音高偏移、滤波 A/B 控制字和音量目标，更新采样步进与平滑器。

控制状态使用固定数组。随机 LFO 共用当前引擎实例的 32 位发生器，Panic／Prepare 重置状态；声部抢占淡出保留自己的调制状态。三类主 EG 均接入 AMS 阈值重触发；Amp 释放后停止接受重触发，Pitch／Filter 保留原规则。音频线程不新增分配、文件读取或锁。

## 模块与参数

| 模块 | 已连接内容 | 原始依据（解压镜像文件偏移） |
| --- | --- | --- |
| `NativeLFO` | 18 种波形、整数 Shape／Offset、Shape AMS、自由速率、两级频率 AMS、随机周期、Delay、Fade、节拍同步、相位暂停 | `0x200208`、`0x200598`、`0x200778`、`0x200A3C`；OSC `+0x30/+0x4C` 的两个 28 字节块 |
| `NativeModulation` | 七种 Mixer，保持 Smoothing 和 Gate 状态；LFO、包络、力度、键盘跟踪和 MIDI 来源 | `0x20119C`；OSC `+0x14C/+0x164` |
| `PitchEnvelope` | 有符号起始／Attack／Decay／归零／Release 电平、原曲线与时间表、级别／时间 AMS、阈值重触发 | `0x1FF9B4`、`0x1FFC54`、`0x1FFD34`；Program `+0x520` |
| 音高目标 | 分段深度曲线、基础深度与动态 AMS 分开处理淡入、原整数步进表与样本限幅 | `0x1FF1A0`、`0x1FF38C`；OSC `+0x68` |
| `NativeFilter` | 动态截止／共振／输出 AMS、两路 LFO 和 Filter EG；Single、Serial、Parallel、24dB 四种连接 | `0x1FB4B0`；OSC `+0x88/+0x90/+0xB4`；原参数手册 P–FILTER BASIC |
| `NativeVoice` | 动态 Amp AMS、两路 LFO 音量目标，各 OSC 独立混音电平 | `0x1F9DD4` |

LFO1 还按原 getter 接入 CC76 的自由频率调整和起音时 CC78 的 Delay 调整。

MIDI 来源按通道保存：多音压力、通道压力、弯音，以及 CC1/2/4、16–21、64–67、80–83、85–88。单双极来源保留原整数缩放；从未接收的 CC 使用无效标记，避免将未接收的双极控制器解释成负满值。CC121 重置该通道，Panic 重置整个引擎。Part 层的控制器屏蔽位没有另建插件参数。

## 具体边界

滤波控制字的整数运算和四种连接有原始依据；控制字到 Hz/Q 的映射仍采用现有工程近似，24dB 使用两级 biquad。这部分不能称为原 TG 音频等效。

当前接入每 OSC 的两路 LFO。公共 LFO 来源 8、原 Tone Adjust 参数覆盖、非 Key Sync 状态的原分配器继承选择仍未完整接通。现有每声部初始化不替代原分配器的完整时序。原 Part 控制器屏蔽位、TG 硅片响应、完整 IFX/MFX 和实琴音频验收也不在这些自动回归的证明范围内。
