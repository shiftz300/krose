# Krose 插件实现计划

产品目标是 macOS arm64 上可演奏、可自动化、可恢复工程的 VST3 和独立程序。外观以 `design/krose-fixed-ui.html` 和两张整机图为准，逻辑画布 1472 × 648。首版使用本地冻结资源中的七个 Program。鼓组音色可以用 MIDI 或琴键演奏，面板不设 Pad 或鼓轨。音频线程独立于编辑器运行。

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 0 · 定稿 | 界面源码、布局、字体、展开与收起图、实现计划 | 可离线打开设计，当前两个引擎及编译后的 VST3 通过现有五项测试 |
| 1 · 编辑器与宿主 | 将定稿布局接入 VST3 和独立程序。音色选择从实际 Program 列表生成。先打通键盘、踏板、弯音、音量、力度和宿主回写 | 用宿主自动化、屏幕输入和工程重开核对。旧参数 0–5 及 Program 编号保持兼容 |
| 2 · 音色与演奏 | PAN、截止频率、共振、AMP/FILTER 包络、复音／单音／连奏与滑音，SW1/2 按 Program 分配 | 新参数追加 ID。中性参数与当前音频基线一致，检查复音抢占、延音、重复音和跨块 MIDI |
| 3 · 琶音器 | ARP、Latch、Pattern、Rate、Gate、Swing、内部速度与宿主同步 | 变速、停播、松键和 Panic 可复现，无挂音，分块不改变音符序列 |
| 4 · 效果与保存 | 依据 Program 路由接入 EQ、Limiter 和空间效果，LCD 与效果窗共用原生参数，支持保存和比较 | 分槽旁通、参数回读、项目重载及渲染差异可检验。折叠 FX 只影响显示 |
| 5 · 整体验收 | VST3 和独立程序打包、离线音频回归、原生窗口交互与宿主重开 | 记录 CTest、Steinberg validator、实时开销和实际宿主覆盖范围，区分本机测试与发行签名 |

每个可独立验收的阶段或阶段内可运行增量单独提交并推送。仓库保留源码、设计与验收记录。本机 PCM 包继续按现有机制装入本地产物。专用 TG/DSP 的近似行为沿用逆向交接中的证据分级。
