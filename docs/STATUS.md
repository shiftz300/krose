## 交互、性能与输入边界复查

0.3.1 包含本轮交互、性能与输入边界修复。Release／LTO／PGO 构建，20 项 CTest 和 18 项 ASan／UBSan 核心测试通过。原生 Cocoa 测试检查 Compare、旧映射迁移、新 FX MIDI 控制和窗口缩放；独立程序中实际完成音色保存、修改、重新载入及 Mod／滚轮操作。

压缩器改为分贝域比例计算，保留已有固定 makeup；独立公式测试覆盖 1:1–20:1、多个阈值和左右声道联动。五种采样率 32／44.1／48／96／192 kHz 下反复切换所有 FX 类型、自动化参数极值、静音和尾音。被测实时路径未发生 C++ 堆分配或释放。

同一本机 arm64 Release，48 kHz／128 帧，各场景测量 5 秒，包含原生窗口和测试宿主：

| 场景 | 平均 CPU（单核 = 100%） | 平均物理占用 | 音频回调 p95 |
| --- | ---: | ---: | ---: |
| 关闭编辑器、空闲 | 2.1% | 130 MiB | 0.016 ms |
| 编辑器空闲 | 2.3% | 212 MiB | 0.017 ms |
| Concert 32 音 | 6.2% | 252 MiB | 0.233 ms |
| Factory 32 音 | 6.9% | 191 MiB | 0.256 ms |
| 8 音持续切换音色 | 6.7% | 260 MiB | 0.089 ms |
| FX 收放动画 | 6.4% | 328 MiB | 0.015 ms |

全部场景未超过 2.667 ms 音频块预算。动画帧间隔中位 16.66 ms、p95 17.56 ms；绘制 CPU p95 0.59 ms。切音色瞬时峰值 364 MiB，动画峰值 333 MiB；此处包含 Metal／窗口与测试宿主，不等于纯采样内存。短测结果用于检查本轮回退，不代替真实 DAW 长时间运行。

边界保持足够余量：

- JSON 读写上限 8 MiB、嵌套 64 层，当前音色约 2 KiB；未知附加字段可保留或忽略。限制只用于控制异常输入的解析成本。
- 工程／音色参数先整体验证再应用，允许量程的十亿分之一浮点误差；NaN、Inf、明显越界和损坏映射拒绝加载。
- 保存使用同目录独占临时文件及原子替换，失败保留原文件；界面销毁后文件对话框回调失效。
- 采样表总长度在分配前与文件长度核对；延续既有采样偏移、帧数、区域、编码及截断检查。
- MIDI 和自动化继续使用固定队列；溢出释放声音或保留每个参数的最终值，防止卡音。没有新增 CPU 或复音限额。
- SDK 缩放入口补上宿主窗口接口缺失／拒绝检查，不能缩放时保留原尺寸；缺失、拒绝、接受三种情况均由原生测试覆盖。

本轮 Windows 的宏命名冲突已在源码修复；Windows 构建、不同 DPI 和安装器尚需目标平台验证。0.3.1 的跨平台安装包由标签 CI 构建，远端构建结果需单独核验。现有原厂效果／用户 ARP／缺失采样等还原范围仍以本页上表为准。

验证结果：

- Release 构建及 23 项 CTest 通过；ASan／UBSan 的 21 项核心与接口检查通过。macOS 不支持本工具链的 LeakSanitizer，未将泄漏检查列为通过项。
- 61 组普通、冷切换、FX、ARP 与高增益检查，加上 24 组 31–36 声部边界检查。36 声部切换时，首样本的额外跳变从 0.03549 降至 0；高增益用例峰值从 5.04665 降至 0.999。被测路径未检出非有限输出。
- 新增回归覆盖 32／48／96／192 kHz、32／33／36／64／128 声部与连续尾音溢出，被测音频路径无 C++ 堆分配。显示环另有生产／消费线程并发检查。
- 原生交互测试通过 Compare、数值编辑、菜单、键盘、ARP、缩放及编辑器重开；独立程序真实执行 `.krose` 保存、修改、Compare、载入和再次保存，恢复文件全部参数一致。
- Ableton Live 12.4.3 实际导入 TH06 存档多轨 MIDI《明治十七年的上海爱丽丝》，12 个 Krose 实例、5,510 个音符，选择相近原厂音色并混用四槽 FX；44.1 kHz、128 帧完成播放检查。保存后销毁并重建实例，两次 99.02 秒、24-bit WAV 导出长度、峰值和 RMS 一致；8,733,642 个声道采样值中仅 93 个相差 1 LSB。此为宿主稳定性测试，不是 CD 配器还原验收。MIDI [下载来源](https://www.soundmusicsys.com/content/MIDI/Games/Touhou/6/th06_07.mid)。

本机 arm64、Release O3，测试构建关闭 PGO／LTO，以便快速迭代；发行构建的默认优化设置未更改。48 kHz／128 帧、32 音、四种 FX 同时可视化，测量 5 秒：整个 SDK 测试宿主平均 CPU 11.05%（单核 = 100%）、平均物理占用 307 MiB，音频回调 p95 0.260 ms、最大 0.486 ms，无超预算；正常绘制 p95 0.456 ms。普通控件动画帧间隔中位 16.53 ms、p95 17.56 ms；结束后宿主 CPU 回落至 2.23%。这些短测包含窗口与 Metal，不代表所有机器或长期运行上限。
